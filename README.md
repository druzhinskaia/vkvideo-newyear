# До курантов

Интерактивный концепт для VK Видео. Зритель выбирает, с кем смотрит и сколько времени осталось. Прототип обновляет список роликов, показывает видеопревью и сохраняет избранное в браузере.

В разделе «Отзывы» собраны ссылки на публичные свидетельства, на которых основана продуктовая гипотеза. В разделе «A/B-тест» описаны контроль, эксперимент и целевая метрика.

Каталог демонстрационный. Превью — короткие анимированные фрагменты из сгенерированных иллюстраций. Статический сайт работает без сборки и API.

Локально откройте `index.html` через любой статический HTTP-сервер.
